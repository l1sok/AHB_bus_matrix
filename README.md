# «Разработка СФ-блока неблокирующего коммутатора шин протокола AMBA AHB»

Работа посвящена разработке параметризуемого RTL-модуля неблокирующей коммутации шин AMBA AHB, предназначенного для маршрутизации транзакций между несколькими ведущими и ведомыми устройствами в составе системы на кристалле.

В рамках работы был разработан аппаратный блок коммутации, основанный на матричной архитектуре межсоединения. В отличие от архитектуры общей шины, такое решение позволяет выполнять независимые обращения к различным ведомым устройствам параллельно, а конфликтный доступ к одному ведомому устройству обрабатывать с помощью локального арбитража.

Основные возможности разработанного модуля:

* подключение нескольких ведущих и ведомых AHB-интерфейсов;
* маршрутизация транзакций по адресу;
* поддержка режимов декодирования адресов TOR и NAPOT;
* локальный арбитраж конфликтных запросов;
* обработка состояний ожидания;
* обработка обращений к неописанным адресным областям через default slave;
* поддержка AHB-буферов;
* параметризация конфигурации RTL-модуля.

## Состав материалов

В репозитории представлены материалы, подготовленные в рамках выполнения и защиты ВКР:

* пояснительная записка;
* презентация к защите;

В ходе работы выполнены:

1. анализ протокола AMBA AHB и вариантов организации AHB-интерконнекта;
2. разработка микроархитектуры неблокирующего коммутатора;
3. RTL-описание модуля на SystemVerilog;
4. разработка тестового окружения с использованием AHB VIP;
5. функциональная верификация с применением SystemVerilog Assertions;
6. сравнение производительности с архитектурой общей шины;
7. оценка аппаратных затрат по результатам синтеза.

Результаты моделирования подтвердили корректность работы разработанного модуля и показали увеличение эффективной пропускной способности по сравнению с архитектурой общей шины. Результаты синтеза позволили оценить аппаратные затраты выбранного архитектурного решения.

## Используемые технологии
* SystemVerilog;
* AMBA AHB;
* RTL design;
* Functional Verification;
* SystemVerilog Assertions;
* логический синтез;
* анализ производительности и аппаратных затрат.
